# Memorizer

יישום מותאם לטלפון לתרגול משפטים, טענות, הגדרות ונוסחאות, עם מפת מושגים שמציגה את הקשרים ביניהם. הממשק וחומרי הדוגמה בעברית ובכיווניות מימין לשמאל; נוסחאות מוצגות משמאל לימין.

## אפשרויות

- תרגול שאלות טריוויה בסדר אקראי, עם הסברים וחזרה על שאלות שבהן טעית.
- יצירת קורסים ועריכת חומרי הלמידה ושאלות התרגול.
- חיבור בין פריטי חומר בשדה ״מתבסס על״ וחקירת הקשרים במפת המושגים.
- הזנת נוסחאות בתחביר LaTeX ללא סימני דולר, באמצעות עותק מקומי של KaTeX.
- שמירת התקדמות בדפדפן וייצוא או ייבוא גיבוי בפורמט JSON.

הקורסים אלגברה לינארית ואותות אקראיים כוללים חומר לדוגמה. יש להתאים את הניסוחים והתנאים לקורס הנלמד. אפשר להוסיף חומר גם ללא שאלת טריוויה.

## הפעלה

אפשר לפתוח את `dist/index.html` ישירות, או להגיש את תיקיית `dist/` באמצעות שרת קבצים סטטי. אין צורך בהתקנה, בבנייה או בחיבור לשירות חיצוני. כל נכסי היישום, כולל גופני הנוסחאות, כלולים בקבצים המקומיים.

## בדיקות

מפעילים את הפקודות הבאות מתיקיית הפרויקט, באמצעות Node.js 22 ומעלה:

```sh
node scripts/check.mjs
node scripts/check-hebrew.mjs
```

הבדיקות מאמתות את שאלות הדוגמה, הנוסחאות, הקשרים, הקבצים המקומיים, הגדרות השפה והעברת הדוגמאות הישנות לעברית. הבדיקות אינן מחליפות בדיקה חזותית בדפדפן.

## אחסון וגיבויים

החומרים וההתקדמות נשמרים בדפדפן שבו משתמשים. אין סנכרון אוטומטי בין מכשירים. יש לייצא גיבוי כדי לעבור למכשיר או לכתובת אתר אחרים. ניקוי נתוני האתר או שימוש בגלישה פרטית עלולים למחוק את הנתונים.

ייבוא גיבוי מחליף את החומרים וההתקדמות רק לאחר אישור. קובץ לא תקין נדחה ללא החלפת הנתונים. מפתח האחסון הישן נשמר כדי להגן על הנתונים הקיימים. דוגמאות מקוריות באנגלית שלא נערכו מזוהות ומוצגות בעברית; חומר שנערך בידי המשתמש והתקדמות קיימת נשמרים.

״שליטה טובה״ פירושה לפחות שתי תשובות נכונות, כאשר התשובה האחרונה נכונה. זהו מדד בסיסי לזכירה. שינוי שאלה, אפשרויות או תשובה נכונה מאפס את ההיסטוריה של אותה שאלה. סיום תרגול סופר רק שאלות שנענו.

## פרסום באמצעות GitHub Pages

אפשר להעתיק את תוכן `dist/` לתיקיית הפרסום במאגר GitHub, ולבחור בענף ובתיקייה תחת **Settings → Pages → Deploy from a branch**. יש לכלול את הקובץ הריק `.nojekyll`. הנתיבים היחסיים תומכים גם באתר שנמצא בתת־תיקייה.

GitHub Pages מגיש קבצים סטטיים ואינו מספק שרת יישום. הוספת סנכרון אוטומטי בעתיד תחייב שירות נתונים עם הזדהות. אין להכניס מפתחות סודיים או אסימוני גישה לקוד הלקוח.

## מבנה הגיבוי

הגיבוי משתמש ב־`version: 1` ובשדות `courses`, `items`, `progress`, `selectedCourse`. כל פריט כולל מזהה, קורס, כותרת, סוג, נושא, ניסוח, נוסחה, שאלה, ארבע אפשרויות, אינדקס של התשובה הנכונה, הסבר ורשימת מזהי הפריטים שעליהם הוא מתבסס. המזהים חייבים להיות ייחודיים והקשרים מוגבלים לאותו קורס. שאלה ריקה משאירה את הפריט מחוץ לטריוויה. הקודים הפנימיים של סוגי החומר נשארו תואמים לגיבויים הישנים.

## קבצים

- `dist/index.html` — מעטפת היישום וחלונות העריכה.
- `dist/style.css` — עיצוב מותאם למסכים ולכיווניות עברית.
- `dist/app.js` — תרגול, עריכה, מפה, שמירה וגיבויים.
- `dist/seed.js` — חומרי דוגמה והעברת דוגמאות מקוריות לעברית.
- `dist/katex.min.js`, `dist/katex.min.css`, `dist/fonts/` — קובצי KaTeX בגרסה 0.16.22.
- `dist/KATEX-LICENSE.txt` — רישיון ספריית הנוסחאות.

## תוחלת ושונות מותנות — אותות אקראיים

נוספו 65 פריטי שינון ושאלות, עם הגדרות, תנאים, נוסחאות, מסיחים והסברים. הנושאים כוללים פילוגים מעורבים, החלקה, שונות שלמה, שערוך אופטימלי, התניה גאוסית, סכומים וזמנים אקראיים, תהליכי פואסון, טלגרף, פאזה אקראית ושרשראות מרקוב.

בבורר יחידת הלימוד אפשר לבחור את כל היחידה או אחת מחמש קבוצות. תחת ״מקור״ בכל פריט מופיעים שם הקובץ, עמודי ה־PDF והסעיף. ״נגזר מהתרגול״ מסמן תוצאה שהוסקה מן הדוגמה, ו״נוסחת השלמה״ מסמנת נוסחת יסוד משלימה שלא נטען כי נוסחה במפורש בעמוד. המספור מתייחס לשמות הקבצים שהועלו, שחלקם שונים מהמספר בכותרת המסמך.

תחת ״תוחלת מותנית״ מופיעים רק פריטים שבנוסחה שלהם יש תוחלת מותנית. חמש הגדרות ההסתברות, הצפיפות, ההתפלגות ובייס מופיעות בנפרד תחת ״הסתברות ופילוגים מותנים״. גרסה 2 מעדכנת את הסיווג גם בחומר שכבר נשמר, בלי לשחזר מחיקות או לשנות התקדמות.

קובצי המקור עצמם אינם כלולים באתר. פריטי התוכן כלולים ב־`dist/conditional-signals.js`. עדכון ראשון מוסיף אותם פעם אחת ובוחר בקורס אותות אקראיים. לאחר שמירה, גיבויים כוללים גם את `contentPacks`, המונע שכפול ושומר על מחיקות ועריכות אישיות. שינוי חומר מתוך החבילה שומר על שיוך היחידה והמקורות ומסומן כעריכה.

בדיקת התוכן והמיזוג:

```sh
node scripts/check-course-content.mjs
```

## גאוסיות — שתי יחידות נפרדות

הכרטיסים המובנים ביחידות הגאוסיות הוסרו. היחידות זמינות לכרטיסים שנוספו ידנית.

המקורות מפורטים בכרטיסים, בעיקר תרגולים 02, 03, 04, 05 ו־08. נוסחאות השלמה ותוצאות שנגזרו מהתרגול מסומנות. העדכון מוסיף את החבילה פעם אחת, שומר עריכות, מחיקות והתקדמות, ומשמיט קשרים למושגים שנמחקו במכשיר לפני התקנת החבילה.

```sh
node scripts/check-gaussian-content.mjs
```
